# OA Placement Prep

Personal notes on Online Assessment (OA) questions asked by companies — collected from my own campus drives and from friends/seniors at other colleges. Used to revise before placements.

## How this is organized

- [`companies/`](companies/) — one file per company. Each file logs every OA round reported for that company: question patterns, topics, difficulty, and source (my campus vs. another college, with date).
- [`companies/TEMPLATE.md`](companies/TEMPLATE.md) — copy this when adding a new company.

## Adding a new entry

1. Copy `companies/TEMPLATE.md` to `companies/<company-name>.md` (lowercase, hyphenated) if the company doesn't exist yet.
2. Add a new `## Round — <Role> (<Date>, <Campus/Source>)` section for each OA instance.
3. Fill in question details, topics tested, and any personal notes (what tripped you up, what to revise).
